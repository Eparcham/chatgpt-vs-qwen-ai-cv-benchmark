# Qwen artifacts

This folder contains:

- the historical 30-task Qwen 3.8 120B answer file,
- the 15 Qwen-authored Cross-Evaluation questions,
- the private reference/test version of those questions,
- Qwen answers to the 15 ChatGPT-authored questions,
- the final Qwen-authored Cross-Evaluation task artifacts.

The Qwen model label is the benchmark operator-provided label. The archived API
answer artifacts do not independently establish the exact server-side model build,
quantization or inference engine.
